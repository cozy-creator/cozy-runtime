# GPU qualification

Hardware qualification is not hosted CLI acceptance. The repository's current real SDXL
owners remain:

- `scripts/pipeline-live.py image`: the staged 6.46 GiB pipeline and real image output;
- `scripts/pipeline-live.py arms`: undeclared access and the quantified physical floor.

The deleted `scripts/cli-live.py identity` compared those private facts with a model-bound
`cozy-runtime run`. That local flat-binding interface no longer exists: the current command
refuses with exit 6 and requires Tensorhub's selected Plan/RMB/MCC provision closure. There
is consequently no honest public GPU CLI result to compare. Recreating the removed binding
path for a qualification would weaken the production boundary, so this scenario is retired
rather than moved or falsely reported as passing.

The supported weightless `cozy-runtime run --offline` path is network-cut in
`proofs/cli/run.sh`. A future production GPU qualification belongs to the provisioned
`serve` boundary and should be added only with a real RecordOwner and exact release closure.
