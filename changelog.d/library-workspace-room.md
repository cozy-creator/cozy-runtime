A library that catches an out-of-memory now gets its room: when torch's allocator refuses a request, the Runtime refreshes torch's limit and unmaps idle weights before the library tries again. cuDNN used to fall back to a convolution that needs no workspace, 4-7x slower, and torch kept that choice for the shape for the rest of the process. SeedVR2's VAE on an 8 GB card: encode 11.7 → 5.2 s, decode 21.5 → 14.5 s per window.
Before a stage plans, torch's idle cache beyond that stage's measured activations goes back to the driver, and a stage's activation peak no longer counts the cache it started with. A VAE decode's leftover 5.5 GiB had shrunk the next transformer stage to a 0.5 GiB budget.
