A call's executor start and weight load are named phases ("Starting model executor", "Loading model weights"), timed on the parent's record. The display no longer reads them as "Checking model inputs": in run 1516 that label covered 12.6 s per Qwen reference and 25.8 s for H3 segment 1, while the check itself took 0.1 s. A package call's failure no longer retires its parent's executor, so the run after a failed one skips a 7.8 s parent start. gpu.wait names the waiting call (`function`, `label`), and a wait on the run's own calls reads "N in use by this run's other calls".
