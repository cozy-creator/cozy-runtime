The machine runs the kernel boot for each installed generation (`python -m cozy_runtime.internal.machine_kernels` under the generation's seal): the attention ladder for each card, then Sol's card objects. A site that will run a kernel still compiling waits for it, judged by the build's measured progress, and the request shows `compiling <kernel>`; it never runs another kernel in its place (Sol's dense reference, its sparse object and the fused glue included). A ranked kernel no site runs is not waited for. Compiled-kernel keys carry the NVIDIA driver version, so existing entries rebuild once. Removed: the image kernel site (`kernel_site`, for executors before 0.18.70) and the request-start upgrade to a kernel that finished compiling.
