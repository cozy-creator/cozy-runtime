A demand prefetch that runs out of memory retries only after the refused attempt is gone. The retry used to run inside the `except` clause, where the traceback still held the fill that the first attempt's host read had admitted. It then prepared the same region and failed the request with `region is already being filled`: Hunyuan-Image-3 0.1.2 on a 48 GB L40S, Runtime 0.35.6, pod-session 41017494524, run 5. A host read now creates its copy stream before admission, declares that stream as the fill's consumer, and releases a failed fill before the error propagates.
