Its pool's size is a guess from an eager pass's peak, and one run of that holds the same blocks in another layout: a prompt LM's decode after another model, or with a long prompt, had its second `repeat_kv` block find no run (16 MiB at a 2,048-token window on a 4090 and an H100, 70 and 86 MiB in qwen-image-2's rewriter on an H100 with 66 GiB free), and decoded the rest of the call eagerly. A decode's record lists these captures, each its guess and the room it took (`decode.regrown`), and the request the refusals they answered (`regrown`, beside `retries`), so the package contract doesn't call them swallowed.
