Memory is planned before every op by one policy (`internal/memory.py`): each component's weights come onto the GPU only when an op of it runs, move to host memory (else back to the store) when another op needs the room, and stream block by block when a component does not fit whole; VAE decodes and encodes tile only when the measured working memory cannot fit untiled. An out-of-memory error inside an op whose state can be put back runs that op again with more room; any other ends the run typed, with its numbers, and keeps the executor serving. The Worker grants each executor its device bytes from `gpu.budget` in `etc/cozy/runtime.yaml` (sizes, bytes or a per-GPU map), else from what the driver has free, and makes room from idle tenants least recently used first. Replaces the residency plane, construction-time paging, the Worker's per-shape peaks and the decode stopgap.
