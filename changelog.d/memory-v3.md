Memory placement follows each managed operation, with machine-level grants, queued-use retention and bounded store prefetch. Host copies reserve shared capacity, aliased tensors move by backing storage, and grouped operations agree readiness before entering collectives. CPU imports can prepare ahead of demand; device initialization and warmup wait for device ownership and a memory grant. Invalid `gpu.budget` values refuse instead of silently removing the limit.

Recoverable OOMs replay only an explicitly declared operation after restoring its state and establishing additional room. Recovery preserves authored tiling and numerical settings; terminal failures retain an executor only when its state was restored. Replaces the old residency/paging policy and automatic decode-tiling stopgap. GPU budget, numerical-equivalence and performance qualification are tracked in tracker #246 and remain required before release.
