Hard cut: `author.denoise_loop` is gone, with the native loop programs (`internal.loop`, `internal.prepared`, the `_execution` kernel module), `cozy_runtime.schedule` and `rng.counter_seed`. A package writes a plain `for` loop and calls its model methods (`author/README.md`). `ctx.progress(i, n)` reports a step, optional; every component call is a cancellation point; each component root call records and replays its own CUDA graph, as before. `stepcache.running(policy, n, device)` with `run.step(i)` replaces `denoise_loop(cache=)`, and its model calls run eagerly. A model call outside `attention_scope` attends dense instead of raising. `retained(nbytes)` always returns a store, and holds plain tensors outside an executor. Contract rule `host_sync_in_step` is gone. `execution.loops` is no longer in a run's record.
