Author SDK hard cut (xs-198). `call(target, request, /, *, models=..., assets=...)` takes one typed request struct; model choices go in `models={slot: ModelChoice}`, a handler's `Files` input in `assets=` (the call's own `assets` field; TensorD hands it to the callee's `Files` parameter). Another package is an ordinary locked dependency called through a generated `Operation[Request, Result]` (`cozy-runtime calls <distribution> <file.py>`), never by importing its function; describe checks the reference's request, result and model slots against the locked callee. Runtime builtins take typed request structs. `Outputs.save_image` is gone: return, publish or pass `ImageFile.from_image(image)` (lossless WebP, PNG over 16383 px; `format=` overrides), which the SDK encodes once, within the field's `FileBound`. A result's float field takes an int. `accelerator` defaults to the GPU only when the function has a constructed `Model` argument. Raw `Weights` are read from the machine's model store; a call's own store holds only its weights outputs.
