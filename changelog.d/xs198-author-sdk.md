Author SDK hard cut (xs-198). `call(target, request, /, *, models=..., assets=...)` takes one typed request struct; model choices go in `models={slot: ModelChoice}`, a handler's separate `Files` in `assets=`. Another package is called through a generated `Operation[Request, Result]` (`cozy-runtime calls <distribution> <file.py>`), never by importing its function. Runtime builtins take typed request structs. `Outputs.save_image` is gone: return, publish or pass `ImageFile.from_image(image)` (lossless WebP, PNG over 16383 px; `format=` overrides), which the SDK encodes once, within the field's `FileBound`. `accelerator` defaults to the GPU only when the function has a constructed `Model` argument. Raw `Weights` are read from the machine's model store; a call's own store holds only its weights outputs.
