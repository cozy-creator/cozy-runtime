Back-to-back attempts hand off faster. An attempt's reply carries the executor's after-state (card figures and rank processes), so the ledger closes without a `Probe` round trip; an older executor's reply lacks it and is probed as before. Run timing snapshots, the `executor` record, call phases and each GPU scheduling pass's `gpu.*` events are written in the journal's deferred batch, and every later journal access reads them first. A warm attempt now commits only its dispatch mark and its terminal (7 durable commits per attempt before). A reusable executor's GPUs return to the scheduler as soon as its reply is absorbed, before the call's finalizing phase is recorded. An unpinned attempt reuses its entry attention walk for `attention.restored`.
