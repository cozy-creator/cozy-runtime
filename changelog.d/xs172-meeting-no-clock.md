A multi-GPU run no longer fails `group_diverged` because one GPU computes for a long time while the others wait for it (a hosted text encoder on a slow host, a long decode or upscale): a meeting waits for a GPU as long as that GPU lives, instead of 5 minutes (30 for a hosted call's home). A GPU that failed, died, returned early or reached a different call is still named at once, and a cancel still ends the run at once. A wait longer than 10 s shows as the run's stage, "waiting for GPU 1: hosted text_encoder".
