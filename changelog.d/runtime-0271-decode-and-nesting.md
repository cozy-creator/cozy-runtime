Weight reads nest as deep as bakes and placements need. Only a read that re-enters a region it is already mapping is refused: H3 1.42.0's long_form went three reads deep on a 5090 (run 10531). Media inputs need no declared decoded bound (owner, 2026-10-17): describe no longer refuses `asset_decode_unbounded`, a read no longer refuses `decoded_bound_missing`, and an undeclared field or `Assets` kind reads within the machine's memory and swap, never a flat 2 GiB. The 2 GiB that undeclared `Assets` kinds publish is kept only so their interfaces stay byte-stable. A bound the author declares still narrows that field's reads.
