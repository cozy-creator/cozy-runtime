Fused per-head RMSNorm + RoPE for a package's own attention (xs-134 H): `fusion.HeadNormRope` declares it at module scope (head size, `Rope` layout and rounding, row and weight dtypes), `fusion.install_head_norms(plan, layout, norms)` installs it on the q/k norm modules in `execution_plan`, and `layout.apply(norm, x, layout.tables(rotary))` returns the fused rows or None while eager serves. The same kernel DiTBlock installs; a windowed or dual-stream block (SeedVR2) reaches it without a block declaration.
