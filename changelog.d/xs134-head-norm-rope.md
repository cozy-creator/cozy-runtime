Fused per-head RMSNorm + RoPE for a package's own attention (xs-134 H): `fusion.HeadNormRope` declares it at module scope (head size, `Rope` layout and rounding, row and weight dtypes), `fusion.install_head_norms(plan, layout, norms)` installs it on the q/k norm modules in `execution_plan`, and `layout.apply(norm, x, layout.tables(rotary))` returns the fused rows or None while eager serves. The same kernel DiTBlock installs; a windowed or dual-stream block (SeedVR2) reaches it without a block declaration. Its kernel reads q or k rows at their stride (`rope_rows`): a view of a packed qkv is normalized in place, with no copy; a layout it cannot address serves eager (`apply`, a DiTBlock's q/k norms) or is refused, never read at the wrong offset. `fusion.AdaRows` does the same for a pre-norm adaLN stream's row chains (the kernels `DiTBlock` installs): `install_rows(plan, LAYOUT)` returns a site whose `first` (norm, modulate), `between` (gated residual, norm, modulate) and `last` (gated residual) each run one kernel, or return None while eager serves.
