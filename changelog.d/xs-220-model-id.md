The Runtime names a weights output's model by `model_id` when it writes it (`tensorfs.Writer`) and shows it (`CheckpointItem`), never TensorFS's legacy `repo_id` keyword, which TensorFS 0.26.0 and later accept only as a bridge; that bridge can now go (xs-220, hack audit tensord #9). The `model-sdk` identity check reads `model_id` and runs against TensorFS 0.26.0, the oldest this Runtime installs with.
