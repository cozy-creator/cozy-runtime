A stored Transformers config builds its binding under Transformers 5's strict configs (fix for #1706, which broke SDXL). The store keeps a canonical JSON config, which writes 1.0 as 1; strict configs refuse an int for a float field (CLIP's `initializer_factor`). The binding now gives each such whole number back as a float, sub-configs by their own model types, before it builds the model on the meta device.
