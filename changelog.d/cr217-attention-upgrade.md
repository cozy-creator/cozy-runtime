A step-boundary attention upgrade never self-checks or builds on the request (cr-217). An attention kernel that finished compiling mid-run used to run its self-check, the prebuilt FA3 probe and Sol's FA4 warm on the request thread at the next step boundary. Every attention kernel now opens (built, imported, launched, checked) off the request (`kernel_ready`) and is selected from the boundary after it lands. A request's own `--attention-kernel` still waits for its build.
