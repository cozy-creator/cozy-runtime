`cozy_runtime.differential` (unstable, release gate only, inert unless the machine has `dev = true`): the varena suite's differential arms, which a gate's package copy turns on with `differential.arm(checks=..., press=...)`. It digests every component root call's outputs, records each split decision into the execution record's `loops`, and by arm turns on varena's checks, presses the card before the second request, or runs every component root as written. The hook that did this from package code imported Runtime internals, which Runtime 0.48's contract refuses (cr-329).
