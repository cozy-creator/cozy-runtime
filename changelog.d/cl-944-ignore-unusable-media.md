An input of a modality a function has no use for is ignored with a note, never refused. A prompt reference whose `type` its `Prompt[T]` doesn't take (`<Video1>` in a `Prompt[Image]`) is left out of `references`, and its mention in `text` becomes its name (`<V>` as `V`, `<amy.2>` as `amy`), as Calcifer sends one; a prompt given to a text field becomes its text, its references left out the same way; a file of another modality in a typed file field is dropped from its list or `Files`, or leaves an optional field `None`. Each is one `ignored` adjustment row (`field`, the mention key or input id as `requested`, "this function takes no videos here", source `runtime`). The other inputs keep their input ids. A required field, or a list left under its `min_length`, still refuses, as does a wrong type of the field's own modality.
