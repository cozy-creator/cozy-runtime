No site serves a 4-bit attention kernel by default (Paul, 11-11: in H3 it loses small details and gains little speed). A model that tolerates 4-bit attention (`attention_bits=4`) serves 8-bit kernels: on Ada and Ampere H3's sparse sites take Kitchen INT8 Sol (`kitchen-sol-producer-fast-shared-qkv`) instead of INT4 Q·Kᵀ, and on Blackwell RTX Kitchen INT8 instead of Sage3 NVFP4. 4-bit kernels still serve when pinned with `--attention-kernel`. Machine start no longer builds them.
