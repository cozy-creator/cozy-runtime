A step that waits on the host says where. While a step loop runs, the stepping thread is sampled every 0.1 s; a sample taken while its GPU has nothing queued counts for the innermost code outside the standard library and torch, and each step's codes over one second become stages `host · <code>` in the run record, which `cozy run show` lists. A planner, a compile, a build wait or a child process holding the request thread is named instead of showing only as a long step.
