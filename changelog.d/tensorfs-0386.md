Model pulls on pods no longer stall on DNS: the TensorFS floor is 0.3.86. A pull resolves each host once instead of sending up to 512 lookups to the pod's resolver at once (some answered only after 8 s, and a failed one ended the pull), and a connection races the next address after one silent tick instead of waiting 30 s on each dead IPv6 address. Single-file source downloads use the same downloader as Hub pulls.
