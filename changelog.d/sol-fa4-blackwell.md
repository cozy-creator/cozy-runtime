On B200 and B300 (SM100, SM103) Sol's sparse steps run on FlashAttention-4's block-sparse forward. Sol's own route picks the exact 64x64 blocks, pooled onto FA4's 256x128 tiles (pooling only turns approximated blocks exact); the protected prefix attends every key in the same call; every other 64-token block contributes Sol's block-mean approximation, merged by log-sum-exp in one Triton kernel. The exact tiles take the dense rows' precision: FP8 with Hadamard-rotated Q/K beside `flash-attn4-fp8`, BF16 on a model's exact paths. Upstream's SM100 Sol kernel is no longer compiled or served.
