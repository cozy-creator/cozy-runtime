Anima's fused execution plan and BiRefNet's ingest recipe are no longer in the Runtime: `anima` 0.5.0 installs the plan itself (fused RMSNorm + split-half RoPE through `cozy_runtime._kernels`, which stays), and the `birefnet` package's own `normalize` job prepares its checkpoint. Removed `cozy_runtime.internal.anima_optimization`, the prepare facts `execution_optimization`/`execution_optimization_refusal`, `cozy_runtime.models.birefnet`, `cozy_runtime.models.ingestion`, the builtin `prepare_model` operation and the `model-ingestion-plan` verb. `anima` releases before 0.5.0 run eager on this Runtime (no fused kernels). Creator releases that still ask `model-ingestion-plan` (v0.6.33 and older) refuse to size Hugging Face sources against it: ship it with the Creator release that stops asking.
