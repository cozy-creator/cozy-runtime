The package API is trimmed to a core. `cozy_runtime.author` exports about 50 names; image types moved to `cozy_runtime.image`, field markers to `cozy_runtime.fields`, input files and decoding to `cozy_runtime.media`, and speed-only tools to `cozy_runtime.accel` (`kernels`, `fusion`, `stepcache`, `moe`, `lora`, `rows`, `attention`). `loader.construct(factory)` takes one argument; a Model's serving facts are one `serving = Serving(...)` attribute and encoded leaves are accepted by default; `@uses_components` is an optional hint and method memo is a plain `@memoize`; `ctx.plan`, `phases=`, `memo_version`, `memo_dependencies`, `MemoDistribution`, `MemoResource`, `app.child_task` (now `private=True`), `hidden`, `publishes`, `emits_media`, `demand`, `loader.load` and `register_adapter` are gone. A memoized function is keyed by its package release. `spread` takes a bound method; `Attention` takes `layout=`; a component call under a dense attention layout records a CUDA graph keyed by the layout. A step cache is off across the GPUs of a group.
