The Runtime wheels no longer install `tensord`: the machine is `cozy machine serve`, a role of the `cozy` binary (v0.10.0), which worker images bake. `tensord.pin`, `task machine`, the publish waiver and dev-build's `tensord_ref`/`tensorfs_ref` are gone; every release carries all five files (sdist, pure wheel, and the Linux x86_64 and aarch64 and Windows native wheels with their kernels). TensorFS 0.11 is required (`tensorfs>=0.11,<0.12`).
