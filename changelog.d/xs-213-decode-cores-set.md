The decode cores' Triton kernels are one declared Runtime kernel set (`cozy-decode-cores`, xs-213): every scheme row traced through the cores at each listed param, optional parts and destination dtype (315 entries), built at machine start and prebuilt into the wheel, opened at device init and served once every entry decodes bit for bit as the reference. A decode never compiles: until the set serves, and for a call it does not hold, the reference decodes on the host and copies its result in. ggml's struct kernel takes its struct as an integer `FORM` in place of a function constexpr.
