The static reader is the only way a package is described (cr-269). `describe --conformance`, which imported the app in the package's venv and compared it with the source reading, is removed, with the import-based interface builder behind it (`package_interface.build`, `compare`, `source_facts`) and `discovery.discover`, `discover_distribution` and `assert_locked_environment`. `cozy_runtime.author.describe` is no longer public: the executor freezes the app it serves with `_describe.freeze`. The interface's `operation_identity_unavailable`, which only the import path wrote, is gone. The 18 first-party packages describe byte-identically before and after.
