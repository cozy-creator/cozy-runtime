A checkpoint with no construction config, such as a single file uploaded as it is (a kohya LLLite adapter, an IP-Adapter), now constructs from its safetensors `__metadata__`, where its trainer wrote its architecture (`lllite.cond_dim`), instead of refusing `the checkpoint carries no construction config`. The values are the file's strings, without paths and URLs (`modelspec.implementation`). Nothing changes for a checkpoint that has a config.
