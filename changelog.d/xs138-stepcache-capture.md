A `denoise_loop` under a step cache records and replays like any other loop. Each step's graph is cut at every stack forward's verdict: the rest of the stack in one branch, the cached residual in the other, which native execution runs as an IF/ELSE in its WHILE body, picked by a kernel from the verdict on the device. The cache's state lives in device buffers updated in place, the same operations eager and recorded, so both give the same verdicts and bytes. Eager steps still read each verdict on the host; the loop's `cache` counts every step's from device counters read after the loop. Native execution accepts conditional nodes, their bodies checked and lowered like a child graph's.
