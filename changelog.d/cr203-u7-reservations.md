Caches are reservations; packages carry no memory numbers (cr-203 U7). Hard cut: packages must stop passing the deleted arguments first.
- What Runtime keeps for speed alone is a reservation memory sheds under pressure (`Memory.reserve(owner, nbytes, shed, host=False)`, reached as `Residency.reserve`; `Reservation.resize/using/close`). These are an LM engine's slots and graphs, a component's CUDA graph pool, and a `DerivedCache`'s entries. An idle owner's bytes go at rung 1, before any weight unmaps. A running owner's (`using()`) go at rung 3, after its stage streams finer. Host entries go before a spill to host. `RELEASERS`, `graphs.release` and `lm.release` are deleted.
- `loader.cache(name, max_entries=64)`: the package bounds the entries, the Runtime their bytes. An entry with no room is returned and not kept. `max_bytes` and the `cache_bound` refusal are deleted.
- Deleted: `split(per_element=)`, `Model.batch_fits` (a CFG pair always batches; rung 3 cuts the rows), `WeightResidency.batch_fits`/`per_item`, `weight_policy.batch_fits` and the unused `Derivation.caches`.
