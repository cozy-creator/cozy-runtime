`model.<slot>=<repository>` with no lane now runs a lane of that repository. Before, when the slot declared no default ladder, it was refused with "choose a lane for model: its slot declares none" (runs 1587/1588). The lane is the one the slot's ladder ranks first for this machine, else full precision (bf16, fp16, fp32), else the smallest, from the named release or else the newest one. The pick is reported in the run's preparation progress. A run is refused only if the repository has no lane, and that refusal names the release.
