`cozy_runtime.lora`: one LoRA update rule for the Runtime's PEFT layers and for overlays a package owns. `accumulate` works in place, at the activation's precision, and reads each factor once; it is one GEMM pair (the PEFT layer's update, op for op), or fixed-row chunks when a caller whose rows split across GPUs passes `chunk`. `lora.Hook` is the linear hook those overlays arm (xs-101).
