In a GPU group, a stage none of whose components is sharded (a text encode, an upsample, a decode) runs on one GPU, its components' home or GPU 0, and its result, the random streams' state and any argument it wrote cross to the others, which fetch, hold and compute nothing for it; host tensors cross through one shared mapping the others read in place. A stage runs on every GPU, as before, where an argument or its result cannot cross, it is called inside another stage, or it left state beside its result; the run's record names those (`transport.stages`) (cr-348 B).
