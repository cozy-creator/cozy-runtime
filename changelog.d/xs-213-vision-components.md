A `needs=` key may name a component of a Model argument, `<argument>.<component>` (`needs={"model.vision": "size(request.images) > 0"}`): where its rule is false the machine doesn't fetch that component for the call; the interface row carries it as the slot's `component_needs`. `vlm.VisionLM` builds a Qwen3.5 checkpoint (`qwen3_5`, `qwen3_5_moe`) from three components, as ingest now stores it: `model` (language layers, LM head, token table), `vision` (the vision tower) and `mtp` (the multi-token-prediction head, `lm.Draft`, placed as its own component). A checkpoint stored before the split refuses `checkpoint_layout`: upload its source again. `VisionLM.ask` names no `@uses_components`, so a slot fetches every component its checkpoint holds, less what its rules leave out (xs-213).
