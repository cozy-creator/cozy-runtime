The executor runs on macOS and Windows. On darwin, parent death is a thread watching the parent's exit, armed in the executor after the trampoline's exec. On Windows the seam is a byte-mode named pipe (`winpipe`, named as TensorD's `cozy_platform::ipc` names it), a handle crosses duplicated into the peer, parent death is a thread on the parent's process handle, and the executor's import path holds no `fcntl` or `resource`: one `filelock` (flock, or LockFileEx on the byte `cozy_platform::lock` takes) replaces `fcntl.flock`.
