A script is a single-file unpublished package: a `main` that runs Model slots is served (constructed models, weight plane, memory manager) instead of a job with manifest-only models, and `[tool.cozy.models]` is its default ladder (a lane string or rungs, as `defaults=`). Every attempt may call children: `Start.call_interfaces` installs the callers before the package import and each served attempt gets the call broker. MediaDecoder no longer requires a decodable payload field on entrypoints.
