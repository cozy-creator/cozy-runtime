An image VAE decode whose maps live in host memory (`chunked <rows> host`) copies them on two streams of their own, a band ahead of the one computing, and gathers each map's GroupNorm statistics as it is written instead of reading it again: 0.84 s for SDXL at 1024² on an RTX 4070, from 1.64 s (0.54 s with the maps on the card). A decode pass that runs again after its block ran out of memory now writes the same map: the shortcut pass added into the map it read.
