Attention kernels are chosen from `internal/attention_table.json`: per hardware class, layout (dense or sparse), attention level, head dimension and token bucket of `min(Lq, Lk)` (edges 2048, 12288, 24576, 65536), the kernels fastest first. It is validated strictly at import: every class present, every kernel a Runtime one of at least its cell's precision, on its class's family, and sparse only in sparse cells. `python -m cozy_runtime.internal.attention_table check FILE` runs the same validator. The first table is today's per-family cells copied into every class and bucket, so every site serves what it did; the `DENSE` and `SPARSE` dicts are gone. Machine start builds the first runnable kernel of each bucket of each cell of the card's class.
