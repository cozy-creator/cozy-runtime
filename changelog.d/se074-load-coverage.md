A load says where its construction and checkpoint disagree, and every stored tensor binds (se-074). Each load names, once in the next run's warnings, the stored tensors no destination reads ("checkpoint tensors were not loaded") and the persistent buffers the checkpoint does not store ("persistent buffers are not in the checkpoint"); the model still loads and serves. An unstored persistent buffer keeps its constructed value instead of refusing the load. A stored persistent buffer goes to meta at materialize and binds like a parameter, so a read outside the module's forward gets the checkpoint's value; the substrate no longer decides it (#1700's registration-time swap moved here). A Model class declares deliberate gaps with `unloaded=(patterns)` (stored tensors it never uses, such as a text encoder's LM head) and `derived=(patterns)` (persistent buffers it derives); `uncovered(cls, ignored, unstored)` is the same filter for package proofs.
