Assets and files (xs-135, Paul's VFX terms; Runtime 0.36.0, a hard cut). An asset is a production element: `Asset` (a `name` and an open `kind`, `character`/`prop`/`environment`; subclasses add media and fields) and `PictureAsset` (`image`, `box`), named in a prompt as `<name>` and rendered by one parser (`name_key`, `mentions`, `render` with a package's label for the Nth asset). `ImageRequest.assets` replaces `reference_images` and `reference_boxes`. A file is a file: `ImageAsset`, `VideoAsset`, `AudioAsset`, `FileAsset`/`Asset`, `Assets`, `AssetBound`, `AssetLimits` and `AssetInfo` are now `ImageFile`, `VideoFile`, `AudioFile`, `File`, `Files`, `FileBound`, `FileLimits` and `FileInfo`; importing an old name (or `ReferenceImages`) fails with "built for Runtime < 0.36: use its newest release". The interface's wire keys are unchanged. The static reader extends `Asset` and `PictureAsset`.
