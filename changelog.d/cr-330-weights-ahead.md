A model with a LoRA baked into its weights (H3's turbo, a user LoRA) has its blocks filled and baked together the first time a call needs it, before its forward computes. Varena admits each block by its own prefetch rule: the phase's measured working memory comes first, and idle weights of earlier phases are evicted to make room. Before, each block was read and baked only when the forward reached it, waiting inline on the step's work (PRO6-61's first step took 72.5 s against 61.8 s for later steps). As an attempt opens, its models are read into pinned host memory, largest first, so a group's follower no longer reads its text encoder from disk during conditioning. "Loading" is shown only while the call waits on a fill, and a bake inline with a step counts as that step's work.
