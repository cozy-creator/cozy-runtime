A package locked to an older Runtime calls native operations under a newer worker again. Admission is per operation (request and result schema, additive optional fields tolerated both ways) instead of the whole native interface digest; the executor states its native documents at hello, and released executors that predate this (0.18.30-0.18.49) are matched to the documents they carry. Only an operation this machine cannot serve is refused, naming it: `native operation "<name>" is not offered by this machine's Runtime <version> (executor needs it); run `cozy rental update <rental>``.
