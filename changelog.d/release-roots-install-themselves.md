A release root installs its whole closure itself: the machine reads each release's interface, Python and lock, and the published callees that lock names, at its own Hub (the origin and CA of its grant), so a controller sends only the release and function. A workspace query's `describe` answers a release's interface (the newest release when none is named) from the same Hub, and a PreparePackageSet naming a release without its facts is completed there. Open child Model slots resolve at the machine's own Hub too.
