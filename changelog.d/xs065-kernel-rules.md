Kernel selection depends on no benchmark data (xs-065). A Load no longer runs the decode qualification suite (3-7 s on every machine's first Load of a release; scripts ran it every time) and nothing is kept under `COZY_HOME/qualification`. Whether a decoder or a native leaf serves is a rule (`selection.admit`): a leaf serves on CUDA where the card's `arch` row has every tensor-core format it declares (`LeafProvider.formats`), so a card no one has measured runs each lane natively wherever its tensor cores exist and decodes only where they are missing. A plan takes the encoded GEMM where the package accepts encoded leaves, else the decode floor; the objective, plan scores and banked plan facts are gone, and the load reply drops `qualification`, `calibrated`, `objective` and the measured per-tensor axes. Deleted: `qualification.py`, `planfacts.py`, `cli/qualify.py`, `Capabilities`/`CapabilityRecord` and the probe's timing benches. `probe.py` is the conformance suite, run by tests and by hand on a new family with `python -m cozy_runtime.cli.conformance`.
