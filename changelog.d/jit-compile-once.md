Sol-Attn's SM90 kernel now compiles at most once per key per machine. A persistent kernel store under `<machine root>/var/lib/cozy/kernels` is keyed by every compile input. The first dense step that sees a token count starts a niced, GPU-less builder, and the first sparse call loads the object or waits on that builder. FlashAttention-4's disk cache moves into the same store. Sol's preprocess autotune is pinned, because its candidates differ bitwise.
