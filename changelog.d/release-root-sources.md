A release root's `ModelChoice.source` (`hf://org/repo@commit[/member]` or `civitai://version`) is made on the machine (workspace `release_root_sources`): TensorFS resolves the provider headers, narrows to the named profiles or selects one, the upload pipeline lands only those members within the free disk and converts them, and the model is kept as the local repository `local/source-<key>`. The key is the source and profiles, so an identical root touches no provider. The resolved event names the source, its resolved commit, the profiles and the model's manifest.
