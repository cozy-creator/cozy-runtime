The machine's catalog reads at its own Hub (a lane resolution, a package's bindings, a checkpoint's manifest bytes, and the release reads of a root it installs) present its worker capability (`X-Cozy-Worker-ID`/`X-Cozy-Worker-Token`), so its owner's unpublished Models resolve on the post-cut Hub. No other origin receives it; a refusal surfaces with the Hub's code (e.g. `worker.ended`) and is never retried anonymously.
