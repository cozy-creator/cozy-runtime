Hard cut: `denoise_loop(..., labels=)` replaces `phases=`, and the step receives `label=`. "Phase" stays varena's memory phases. A labeled loop with components keeps its whole call like any other: one graph per distinct label (A B A B records two), each run of a label one native stage of its graph, the runs in step order in one sequence and one pool, with `before` and `after` around them. A first call runs its steps eagerly through each label's first (one step, unlabeled), so every label's kernels and blocks run before its graph records; with steps left it records and runs them natively, else its whole call records at idle. A loop's row carries `gpu_ms`, the GPU's time between CUDA events at its eager steps, recording and native runs.
