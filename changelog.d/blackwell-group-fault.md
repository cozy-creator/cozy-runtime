H3 no longer takes a GPU page fault on a group of Blackwell cards. A Triton kernel set whose signature listed a constexpr out of its parameters' order launched with every later argument one place off (`cozy-sage3-group-mean`, since 0.35.5); a set's signature now takes its kernel's order. A group follower's kernel probes read the real device count during construction, so comfy-kitchen no longer refuses with `Invalid device id`. A self-check that kills its CUDA context says so in the machine's log and refuses that kernel in the next process, instead of faulting every run.
