Each attention site resolves one ready kernel per token bucket of `min(Lq, Lk)` at preparation, a ladder, and each call takes its rung by its whole length, after Ulysses' exchange, so N GPUs pick what one GPU picks. A call its kernel's row refuses goes to the next ready dense kernel of its bucket, then SDPA (a pin's refused call still goes straight to SDPA). A group's followers install rank 0's ladders. The boot record names the table and lists each component's sites by layout, level and head dimension with the kernel per band (the boot line reads `transformer: sageattention <12288, kitchen-int8 >=12288` once a table ranks by length); a run's record lists the bands each kernel's calls fell in (`<2048`, `2048-12287`, ..., `>=65536`; "" for one band) and, per site group, the kernel each band was served by. A package producer serves the bands its ladder gives it. With today's table every site has one band, so every site serves what it did.
