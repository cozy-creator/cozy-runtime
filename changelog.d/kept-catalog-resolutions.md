A machine keeps what it read of a package or model at its Hub across Runtime restarts. That covers the owner's bindings, each release's lanes, each lane's checkpoint and a package's newest release. A run that names a model's repository without a lane reads nothing on warm runs, where it used to read the release's lanes every run, and nothing after a restart. `ForgetPackage` now also names models, and the reads are discarded when the supervising process (the machine agent) starts afresh.
