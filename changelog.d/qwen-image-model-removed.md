Qwen-Image-2.1 is no longer in the Runtime: the `qwen-image-2` package carries its model (since 0.3.0) and the checkpoint's processor files (0.5.0). Removed `cozy_runtime.models.qwen_image21` (the staged model, the vendored Diffusers copy, the `qwen-image-2.1/original/1` ingestion recipe), `cozy_runtime.models._progress` and the `qwen-image21` extra. `qwen-image-2` releases before 0.3.0, and any environment that still locks one, fail at import on this Runtime. Uploading `hf://Qwen/Qwen-Image-2.1` uses the machine's uploader, which keeps the `processor/` files as checkpoint assets.
