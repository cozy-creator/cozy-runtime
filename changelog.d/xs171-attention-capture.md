Dev-only attention capture (`cozy run --attention-capture SPEC`, hidden behind `dev = true`): an attempt whose request carries a capture spec writes, under the spec's directory on the machine, one census row per attention call (site, call, band, kernel, shapes, layout) and, for the named sites and calls, the Q/K/V the kernel receives (BF16, the kept heads over the whole sequence) as safetensors. It is taken right after the call's band is picked, after Ulysses' exchange. Rank 0 only; a call recorded into a CUDA graph is counted but not captured. The spec reaches the executor once TensorFS carries `Invoke.attention_capture`.
