An environment write is the package's only when its own code makes it. Torch's inductor writes back its cache directory whenever it is imported, and diffusers imports it on a GPU, so the executor's seal refused every diffusers package's import (`contract_violation ... TORCHINDUCTOR_CACHE_DIR ... env_write`) on a GPU machine. A library's own write now passes; the package's own `os.environ` writes are still refused.
