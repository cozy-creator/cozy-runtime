Quantize recipes are declared values (`Recipe(lane=, model=, plan=)` in `cozy_runtime.author`), found by the static describe and recorded in the package interface (`recipes`). A package with recipes serves the Runtime's one `quantize` entrypoint, which picks the recipe for the lane and source and writes the lane with its provenance (`metadata.provenance`: package, release, recipe, fingerprint, source, plan). `QuantizationPlan` carries the lane's encoding (none: the plain bf16 lane); code-only lanes are a `DerivationHook`. The defaults `Recipe` is now `DefaultSet`.
