A machine job root granted no device takes the CPU composition slot even when it holds derive-only Model inputs or weights outputs, so a client script that passes its Models to a GPU child no longer fails `child_admission_refused` (run 1223). `MachineExecutionWorkspace.cpu_slot_model_inputs` reports this, asked of the slot predicate itself. A client script composes on CPU unless its metadata sets `[tool.cozy] accelerator = true`; a CPU script that uses CUDA fails `job_needs_accelerator` naming that setting.
