A script is an ordinary package (xs-099): its PEP 723 block is its pyproject.toml and it declares `app = App()` and `@app.entrypoint` functions like any package (`accelerator=`, `defaults=`, `weights=` on the decorator). `script_app`, `ScriptContext`, the `main(ctx)` adapter, `[tool.cozy]` script metadata and the static reader's script branch are deleted. `accelerator=True` is accepted on every function: what absence means, the machine's GPU when it has one.
