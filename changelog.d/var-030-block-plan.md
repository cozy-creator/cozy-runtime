A paged block's wholes are placed together: after one pass of a block that had to keep a whole in host memory, its later passes keep in host memory the set of its wholes that lets the rest fit the card with the fewest bytes crossing the link, and send the block's own output there only where nothing else fits. H3 15 s at a 6 GiB cap kept its sparse steps' out-projection on host and ran each block's tail over the link; it now keeps the sparse attention output there instead, so the block's input and output stay on the card (var-030).
