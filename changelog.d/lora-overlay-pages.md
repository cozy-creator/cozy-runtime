A LoRA overlay a package arms per forward (`lora.Hook`: H3's Turbo, Qwen-Image's Lightning, FLUX.2 [dev] Turbo) is part of each resident page's identity. A block's page serves only a use that wants the overlay it was filled with; any other use drops it (and its model's holds) and refills, baking the armed factors. A block filled outside a Turbo forward (a scope's hold, a base forward, an off-forward read) can no longer stand in for a baked one, and Turbo-baked pages no longer serve a base forward. On CPU every in-forward-armed LoRA was missing. The fill identity names only what every page shares; graphs no longer capture a root with an overlay hook. Bake math and rounding seeds are unchanged.
