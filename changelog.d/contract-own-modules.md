Describe holds only a package's own modules to the package contract. The Runtime's built-in operations were read with site-packages as their project, so every installed library (PIL, numpy, TensorFS) was checked as their own and `describe_environment` refused every environment with `package_contract`, failing each local-code install (`package_prepare_description_failed`). A reader now always names its own top-level modules: `cozy_runtime` for the built-in App, a wheel's RECORD for an install, the source tree's for a project.
