A kernel that finishes compiling during a run serves that run from its next step or stage on: the construction selects again at each step or stage boundary (never per attention call) once a kernel it passed over is built, so a cold machine whose download beats the boot compile no longer runs its fallback for the whole first run. The rank's execution record names which steps served which selection (`attention.segments`: stage, step, kernels, Sol's dense reference), and `observed`/`kernels` cover every kernel the run served. A group's followers take the new kernels once no call holds them.
