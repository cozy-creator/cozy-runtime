`author.denoise_loop`: a resident program that no call keeps is not recorded; the call runs eagerly, which costs no more per step than native execution saves (measured: SDXL 443 vs 431 ms/step on an RTX 3070, Qwen-Image 189 vs 191 ms on an RTX 4090). Kept whole calls, streamed loops and loops without components still record. Region graphs are bypassed only where the loop names blocks. Recording phases are in `execution.loops[].parts_ms`.
