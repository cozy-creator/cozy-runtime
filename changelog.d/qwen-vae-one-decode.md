Anima's VAE has one decode: the exact one in row bands, which already runs a lone frame on one temporal tap with no frame cache. `image_vae.fast_decode` is gone, so diffusers' own norms and upsampling run in float32 again. On an RTX 4070 at 1536², with real Anima latents, it takes 1.27 s against fast_decode's 1.24 s and packages#387's 1.29 s. It uses half their peak (1.30 GiB vs 2.96 GiB) and matches the fp32 decode as closely as #387 does. CPU executors decode exactly too.
