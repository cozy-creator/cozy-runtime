A memoized function's code closure now holds every non-Python file of its packages (what a module reads beside itself through `__file__` or `importlib.resources`), so reading package files no longer drops it to a whole-package memo key; a top-level module's own path still does. A `memo_dependencies` name bound to a tuple at module scope is read like the tuple (cr-240). minimax-h3's pieces, sdxl and qwen-image-2 now key on their closures.
