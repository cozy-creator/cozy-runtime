A run names its GEMM kernels beside its attention kernels. Rank 0 emits `gemm.selected` (value: the kernel, e.g. `cozy-int8`, `comfy-kitchen`, `cozy-fp8`, `torch._scaled_mm`, `cozy-nvfp4-gemv`; fields `component`, `format` int8|fp8|nvfp4, `leaf`, `sites`) for each (component, format, kernel), counted from the kernel each encoded leaf's last call served. `gemm.fallback` (value: the served kernel; fields `component`, `wanted`, `served`, `reason`, `sites`) replaces the "encoded leaf refused, served decoded" and "8-bit op unavailable" warning logs; each is also one warning line, "a GEMM served below its lane", with the same fields, because TensorD before the release that keeps `gemm.*` drops the confession. The int8, fp8 and nvfp4 dispatchers return the kernel with the product.
