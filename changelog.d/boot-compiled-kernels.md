Kernels compile on the machine that runs them, at worker boot, in the background, from pinned source (`python -m cozy_runtime.internal.kernel_sources fetch <dir>` fills an image's `/opt/cozy/kernel-sources`), into an exact-key store reused across executors and boots; the baked kernel site, the numeric attention probe and `cozy-runtime attention-qualify` are removed. Selection serves a kernel once it is compiled, imports and launches, and falls through past one still compiling (to SDPA at worst); a request start picks up a kernel that became ready. Sol is admitted on sm89/sm90/sm100/sm120 with one object per card (sm90: one per 64-token block layout). Fused glue compiles at boot through the same manager. Run evidence lists every chain kernel: served, ready, compiling (progress), failed, absent or unsupported, with its compile time.
