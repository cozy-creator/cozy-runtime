A package can apply a LoRA of its own while an adapter steers (se-127). `lora.Sites(component)`, built with the model, puts the Runtime's overlay hook on every linear of that component; `sites.applied({path: factors})` arms a LoRA for a block of calls, and `lora.Pair` holds one linear's `lora_A`/`lora_B` as most files store them. Armed, the factors bake into the pages filled for those calls, as an overlay's do; unarmed, the hooks add nothing and the component's calls still replay recorded graphs (a package's own `lora.Hook` keeps them eager). Optional: a package that uses none of it is unchanged.
