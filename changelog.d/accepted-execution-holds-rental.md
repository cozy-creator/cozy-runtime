Every accepted, non-terminal machine execution is `active_work`: one queued behind other work or waiting on a delayed retry holds the rental, the same as a running or stopping one. A request this machine can never run (no readable GPU, or an exact GPU count it cannot form) is refused at admission and never journaled. A refused desired revision's fault carries `Fault.desired_state_revision` (worker-protocol a41dcbd) as well as the `revision N` subject.
