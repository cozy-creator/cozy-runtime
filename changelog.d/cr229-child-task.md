`@app.child_task` registers a function only its own package's calls run (cr-229, Paul 10-31; a hard cut). It replaces `@app.entrypoint(internal=True)`: `entrypoint` no longer takes `internal=`, and `child_task` takes `entrypoint`'s options except `hidden`, `implements` and `model_classes`. The static reader reads both; the interface's wire key stays `internal: true`, so every cozy and TensorD release refuses a child task as a root request.
