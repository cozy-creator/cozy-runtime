A release root may name an unpublished installation this machine already holds (`ReleaseRoot.installation_id`, worker-protocol 246bb8f) instead of a published release: the machine resolves its Model slots (provider sources included), installs its published callees from its own lock, and mints the offer as for a release, reading nothing about the root at the Hub. An installation it does not hold is refused with `release_root_installation_absent`, so the controller prepares it and asks again.
