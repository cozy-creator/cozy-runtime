Bundles TensorD 0.5.6: executor groups are no longer sealed to `NCCL_P2P_LEVEL=NVL` (the Runtime sets NCCL's peer level from its measured links); a local package that vendors a dev Runtime wheel runs on its own Runtime where the machine's does not satisfy its pin, and a failed install quotes the installer's stderr; downloads judge a slow range against the ranges running beside it, so a pod whose every range is slow restarts none (TensorFS v0.7.2).
