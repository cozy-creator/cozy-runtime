A package release prepared for several model selections now keeps each prepared placement, keyed by its exact identity (placement, installation and bindings digest). A serving root is checked against its own prepared placement, so it is accepted and waits for the GPU while a workflow job from the same release holds it, instead of being refused with "execution inference does not name the captured root". A private package's model-bound placement is retained the same way, so a private serving root that names it is no longer refused.
