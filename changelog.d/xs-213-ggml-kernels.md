ggml's block types are the `ggml.*` encodings (they were `gguf.*`). On sm80, sm86, sm89 and sm120, weights in `ggml.{q8_0,q5_0,q5_1,q4_k,q5_k,q6_k}` multiply on llama.cpp's own MMVQ and MMQ kernels (`_kernels._ggml`, vendored from b12466), each linear holding at most 32 MiB of working memory beyond its input and output; a token table in those types decodes only the rows it looks up. Elsewhere they decode.
