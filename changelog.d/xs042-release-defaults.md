A Model slot's default names a release only: `defaults={"model": "qwen3.5-9b@0.2.0"}` (and a script's `[tool.cozy.models] model = "…@release"`). GPU ladders and lanes in defaults are refused; describe stops emitting `default_ladder`. Model classes declare `min_bits=` (16|8|4, default 8) and `phase=` ("compute"|"decode", default "compute"), inherited by subclasses; each slot carries `default`, `min_bits` (omitted at 8) and `phase` (omitted at "compute") for TensorD's lane rules (xs-042). `package.toml [bindings]` is gone. Packages published with ladder defaults must be republished.
