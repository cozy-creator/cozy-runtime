`Model.warm` is gone: the Runtime never called it after 0.18.101 (a load always has a call waiting, which pays its own first launches), so `internal/warm.py`, `warm_context`, `fakes.warm_with_fakes`, H3's warm override and the H3 group-warm fixture are deleted. `warm` stays a reserved member name, so packages that still define one describe and load as before; the executor notes such a class once.
