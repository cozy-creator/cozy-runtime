Start a waiting serving execution's executor before its GPU grant, whoever holds the card: the process spawns and imports torch, the Runtime and the package with no device touched (`Start(import_only)`, advertised as `import_only` in the hello), and the grant adopts it and only initializes the device. Older executors are spawned ahead and started at the grant. The prespawn no longer creates a CUDA context or runs kernel launch checks.
