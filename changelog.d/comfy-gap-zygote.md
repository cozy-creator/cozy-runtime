A model's `load()` runs before its device is needed: `loader.construct` builds and walks, and its fit, fill and commit run once `load()` returns. An executor's import-only parent builds a call's model slots ahead (headers, config, `load()`, no device) when TensorD sends it the call's Load, and the executor it forks adopts them; until `load()` returns a package sees its derived buffers on the host. A slot whose construction asks which card, or touches the GPU, is not built ahead, and a parent left holding a thread refuses its Load and every fork (`fork_unsafe`).
