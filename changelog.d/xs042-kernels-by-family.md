Runtime picks GEMM and attention by GPU family, never by card list (xs-042 K). `internal/arch.py` holds the rows (family mma.sync/wgmma/tcgen05, native int8/fp8/fp4) from the compute capability; a cc no row names takes the newest family whose 8-bit op builds for it, with one warning per run. The 8-bit op builds by row (12.1 gets the fp8 TMA GEMM, 11.0 its tcgen05 GEMM). Each attention site takes its family's cell at its level: 16 for a request with `bits=16` (C4) or a sparse site's exact paths, else the model's `attention_bits=` (16|8|4 or component-qualified prefixes, longest wins, unlisted 16); a kernel absent, compiling or failed steps to the next, then up a level, with one warning. A package producer is tried before its base. Deleted: `Model.choose_attention`, `AttentionContext`, `LIKE_PROJECTIONS`, the ranked/pinnable split and per-kernel card sets, `machine_kernels.LADDER` (the boot builds each level's first kernel of the row's cells). Packages that override `choose_attention` must declare `attention_bits` and be republished.
