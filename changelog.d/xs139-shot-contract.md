Runtime 0.37.0, a hard cut (xs-139, Paul 10-31). Named references: `Asset` becomes `Reference` (no free-text `kind`), `PictureAsset` becomes `Picture`, and `ImageRequest.assets` becomes `pictures`; a duplicate name refuses with code `reference_name`. The video interfaces become the shot and upscale contract a project compiles into any package's call: `ShotRequest` takes `prompt`, `duration_s`, `beats`, `style`, `soundscape`, `references` (a union tagged on `kind`: `CharacterReference`, `PropReference`, `EnvironmentReference`, `VideoReference`, `AudioReference`), `plate`, `first_frame`, `last_frame`, `continue_from`, `aspect_ratio`, `seed` and `preset`; `ShotResult` returns `video`, `warnings` and `latents`; `UpscaleRequest` gains `resolution` (the short edge). `ShotAsset`, `WorldState`, `writes` and `ShotResult.frames` are gone. `Implements` and `app.entrypoint(implements=)` are deleted, with the interface document's `implements` key: a project matches request fields by name, and a package states its piece limits as `duration_s` schema extras. A field's `msgspec.Meta(extra=...)` now rides in the interface document as `extra`, verbatim (it was dropped, so minimax-h3's `max_piece_s` never reached a caller); readers ignore what they do not use.
