A host-tier page key is a digest of the component by content, block, stored layout, fill identity and overlay, so the same bytes have one key in every process and package release. A baked block's page names its slot (block and fill identity, whatever the overlay): TensorFS writes it to disk once and every later process reads the merged page instead of the base weights and the LoRA (H3 Turbo's 52 transformer blocks and 51 factor reads). At each phase change the tier reads ahead, into pinned host RAM within free room, the pages of the models of that package the request has not used yet, the largest first: text encoding reads the transformer's, its merged pages from disk once made.
