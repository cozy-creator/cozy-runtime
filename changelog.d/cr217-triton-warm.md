Runtime-owned attention Triton kernels never compile on the request (cr-217). Sage2's and Sage3's fixed-mean kernels took the document length as a constant, so every new video length compiled them at its first step. They now take it at run time (1/N rounds as the constant fold did), one kernel shared by both. Each family's kernels build for every length when its attention kernel opens, off the request (`kernel_ready`). The same goes for the fp8 attention quantiser, whose lengths are no longer specialized.
