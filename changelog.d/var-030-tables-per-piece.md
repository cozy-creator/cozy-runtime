A module without parameters whose per-token tables a rows cut reads (a RoPE's cos and sin) hands them over uncomputed. Where memory is short, the cut computes each piece's rows with that piece, so the table is never whole. Where it runs whole, the tables are computed once and kept, as before. LTX-2.5's 20 s 1080p refine held 3.2 GiB of fp32 RoPE tables before its first block, and a 6 GiB card refused it (var-030 §17).
