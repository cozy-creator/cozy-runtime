- A device OOM no allocation of ours was refused for (a kernel's code at its first launch, local memory, a library's handle: a cold H3 on a full 5090 failed its first `index_select`) no longer fails the run when the forward can run again: the block or component forward it failed runs again once TensorFS has given the driver room, waiting a bounded time for memory other programs took. Each rerun is in the run record (`reruns`). A forward runs again only when its operands show it wrote none of them (version-tracked tensors and plain values).
