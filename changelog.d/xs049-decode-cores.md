Decode cores (xs-049 U1). `internal/decode_cores.py` holds cozytensors' three decode building blocks as generic Triton kernels with an eager torch reference: affine (b-bit codes in U8/I16/I32/U32 words, any pack axis, transposed storage, word/dense/planar fill, low/high/permuted slots, signed or offset codes; `(q - z)s`, `qs + b`, `qs` on a tensor/row/column/row-block grid with `row_major`, `transposed` or `cublas_128x4` blocks and an optional `g_idx`), table (`T[q]s`, with a second-level scale multiplied or divided) and block structs (a scheme's `@triton.jit` struct decoder per element). Both round once into the destination with the spec's bit operations (nearest even, canonical NaN) and launch without FMA contraction, so they match TensorFS's Rust decoder bit for bit. A scheme joins as one `Adapter` row in `encoding/adapters.ADAPTERS`; `CoreDequant` serves each row as a decode provider (kernels on CUDA, eager elsewhere) and the probe qualifies it with the `cores-decode` oracle (random parts, kernel against eager, bit for bit) plus the scheme's spec vectors. The vectors are now TensorFS's per-family files (`encoding/vectors/cases/<family>.json`) and `cores.json`.
