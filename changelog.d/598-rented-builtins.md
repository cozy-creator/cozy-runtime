Runtime 0.18.24 fixes admission of captured Runtime-owned operations on rentals.

Native model metadata preparation and shared quantization retain their exact
captured SDK and numerical dependency snapshot when the supervisor storage
channel is enabled. Admission verifies the sealed receipt, carrier, content and
interpreter identity, then reserves bounded storage before creating the ordinary
placement. Arbitrary rented application packages still require their declared
exact dependency wheels. No model source bytes are discarded or reacquired.

The regression uses an installed Runtime wheel, real Worker and descriptor-four
storage transport, and verifies that edits to controller code after SDK capture
cannot change the admitted implementation. Native build inputs are unchanged.

Completed outcomes now hash the declared result schema with decoded-media bounds,
matching static and imported package interfaces. This lets a successfully produced
bounded PNG or video pass ordinary result collection without rerunning inference.
