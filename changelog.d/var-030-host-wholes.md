A `split`'s whole output goes to host memory per use, not for the rest of its request: the request keeps the largest room that input shape's whole was refused in, and a call in a larger room asks the card again. `split(out=)` no longer computes in place on a whole kept on host: the whole comes back to the card where it now fits, else each window is brought to the card, written and copied back. H3 15 s at a 6 GiB cap kept its out-projection's whole on host for the whole request once it was refused, and its block tail then ran over the link (var-030). The run record's `host_wholes` counts the bytes host wholes crossed the link by.
