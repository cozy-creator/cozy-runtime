- An fp8 model on a card without native fp8 no longer runs out of device memory when a stage binds its weights. Each bound fp8 weight is decoded into a float copy; those copies are now counted in the stage's budget beside the stored bytes, and a bind that still runs out plans again in what is left instead of ending the stage. Components placed together each keep their grain while the budget holds every one's floor at it, so a small component (H3's turbo LoRA) is no longer moved to the sub-block grain to give a larger one more room.
