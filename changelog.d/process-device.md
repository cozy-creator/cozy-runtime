One device per executor: `author.device()` is this process's GPU (a group rank's own `cuda:<rank>`), MPS, or the CPU where none is present, as `accel.present` decides. `Model.device`, `Loader.device` and `ctx.device` all read it (`ctx.device` was always `cuda:0`, `Loader.device` always the CPU), and the Runtime's own GPU tests (int8 leaves, CUDA graphs, SVDQ fitting, attention expectations) use it instead of `torch.cuda.is_available()`.
