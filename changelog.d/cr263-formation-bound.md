A multi-GPU group gives each formation attempt 60 s (forming takes under 2 s) and tries 3 times. A stalled attempt prints every GPU's thread stacks to the run's log, is ended on every GPU, and forms again on a new store; the run's stage says so ("forming the group again, attempt 2 of 3: …"). After the last attempt the run fails with `group_unformed`, naming each GPU and its step ("attempt 3 stalled 60 s: GPU 1 (joined its store, then nothing), GPU 0 (in barrier)"). A GPU 0 stuck in group init, which nothing can interrupt, ends its process after 70 s, so the machine fails the run and frees the GPUs. A stall where NCCL connects over peer memory beyond NVLink keeps that machine's later groups off it until the next boot.
