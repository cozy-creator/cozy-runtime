Kernel build waits wake when the builder exits or the request is canceled, not on a 0.5 s poll, and a compiler job queued in the compile ledger starts when an admitted one exits. A parent awaiting package calls reads the machine's nudges on a thread of its own on every platform, Windows included; a machine that refuses or closes them fails the call (`child_events_refused`, `child_events_closed`) instead of polling every 50 ms. A run waiting for another run's turn (attempts in flight, command order, model scopes) shows "waiting for run N" (or the command it waits for) until the holder ends. The LoRA bake kernel build logs its start and end. TensorD 0.10's `executor.cancel` file is no longer read.
