An image VAE's decode on the weight plane (SDXL's `AutoencoderKL`, Anima's `AutoencoderKLQwenImage`) is exact: layer by layer in row bands, GroupNorm statistics over the whole map, the mid-block attention whole. Memory decides only whether the maps stay on the card or live in host memory. The blended tiled fallback (30 dB from untiled on SDXL) is gone; the mode reads `chunked <rows>` or `chunked <rows> host`.
