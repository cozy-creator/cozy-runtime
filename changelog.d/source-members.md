A model upload's source files and profiles can arrive in any order, and a repeated identical file counts once. A member such as `model (1)+ema.safetensors` is accepted wherever TensorFS accepts it (safe, relative, printable ASCII). Before, each of these was refused as `model_source_file_order`, `model_source_profile_order` or `model_source_file_invalid` after the download finished. Only one member naming two different files, or one slot naming two profiles, is refused.
