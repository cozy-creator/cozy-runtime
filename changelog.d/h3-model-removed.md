MiniMax-H3 is no longer in the Runtime: the `minimax-h3` package carries its model since 1.35.0, and `minimax-h3-tools` 2.15.0 its AdaLN row-label reader. Removed `cozy_runtime.models.minimax_h3` (the models, the Diffusers pipeline integration, conditioner, continuation, AdaLN-pruned DiT, turbo overlay, VAE tiling, tokenizer and processor files and timestep plans) and the `minimax-h3` extra; the Runtime's own Diffusers tests use the `diffusers` dependency group. With BiRefNet's recipe gone too, the empty `cozy_runtime.models` namespace is removed, and static describe reads only `cozy_runtime.derive` as trusted Runtime source. The shared-QKV attention producer recognizes a model's LoRA hooks by `weights.LoRASource`. `minimax-h3` releases up to 1.34.x and `minimax-h3-tools` up to 2.14.1 import the removed module and fail at import on this Runtime.
