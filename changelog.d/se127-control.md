Picture models share one control input. `cozy_runtime.image.Control` is `{image, kind, strength}`, its `kind` one of `depth`, `pose`, `lineart`, `sketch`, `canny`, `inpaint` (`ControlKind`); `inpaint`'s map is the picture with the area to redraw transparent. A function names the kinds it has adapters for, `control: list[Control[Literal["pose", "depth"]]] = []`: the interface lists only those, so the page can cross out the rest, a box draws the list as a group, and a request's control of another kind is dropped with a `warn` row rather than refused. Optional: nothing an author writes changes.
