`AttentionLayout.tau` (xs-134 H): the threshold a step's Sol sparse attention selects key blocks by (Sol-Attn's `tau`; higher keeps fewer), 1.0 by default as before. Every sparse route reads it (upstream Sol, Sol FA4, Kitchen Sol), as does a package's own producer through the active layout, so a model's presets set it per step: minimax-h3's Regenerate `preset` mirrors NVIDIA's `sol_engine` (1.0) and `sol_engine_fast` (1.75).
