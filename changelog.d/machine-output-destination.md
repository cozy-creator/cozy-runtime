A machine job root whose weights output grant names `model://org/name` uploads each Model it returns to that repository through the `upload_checkpoint` effect before the attempt closes, under the root's publication authorization; a memoized root may publish only its own result to that granted destination. Every completed checkpoint upload is journaled as a `checkpoint` execution event, from which Creator settles `cozy run <fn> <in> <org/model> --rental`.
