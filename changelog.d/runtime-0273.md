Runtime 0.27.3 is cut from release/0.27 and replaces the unpublished 0.27.2. Two fixes. An op run in bands no longer fails on a band that lies wholly inside a padding ("narrow(): length must be non-negative", H3 long_form segment 2 on a 5090, run 10683). A stage never refines its grain while a ring held outside its plan keeps the weight set open; under 0.27.2 that refine failed with `LeaseViolation`. On TensorD 0.7.3.
