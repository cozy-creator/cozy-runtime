- A multi-GPU group forms reliably on GPUs joined only by PCI. The group lane's seal now sets `NCCL_P2P_LEVEL=NVL`: NCCL uses GPU-to-GPU peer memory only over NVLink, and other GPUs exchange through host shared memory. With the default, a two-A40 group hung at formation about 4 times in 10 (both GPUs spinning in the first barrier, the run ending after 11 minutes as "Retained preparation is unavailable"). Measured on two A40s: all_reduce 10% and all_to_all 28% lower raw transfer rate with peer memory off; NVLink hosts keep the fast path.
