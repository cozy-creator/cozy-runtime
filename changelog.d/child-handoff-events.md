A parent awaiting managed calls sleeps on a worker nudge socket (`child_events`) instead of polling every 50 ms. Any journal transaction that writes a call result, a native call state or a refusal, any non-log execution event, a closed child and the parent's own cancel wake it. The worker's drive pass starts on each call, finished preparation, execution event and closed child instead of waiting for its 50 ms watchdog cadence, which now only samples deadlines and cancel stalls. Host facts (`nvidia-smi`) are measured once per boot, not on every child call; an unreadable driver or an executor death re-measures. A demanded child reuses its finished exact model preparation unless this worker's store collector ran since, and admission skips the early checkpoint re-verification when a live executor already built that exact construction (retention still verifies natively). An older worker declines `child_events` and its parents keep polling.
