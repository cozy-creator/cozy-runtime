Kitchen's Sol attention can be captured in a CUDA graph when the token count is not a multiple of 64. Its ragged last block's length was written from the host (`lengths[-1] = float(tail)`, a host-to-device copy), so H3's native segments failed capture on the 15 s request (111,334 tokens). The Runtime now applies `lengths[-1:].fill_(float(tail))` to the reviewed comfy-kitchen 0.2.37 wheel as it unpacks it (a recipe text fix, in the kernel key), with identical values, until upstream takes it (Comfy-Org/comfy-kitchen#283).
