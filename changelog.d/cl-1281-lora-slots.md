A LoRA a function applies through a call is a `Weights` argument with a default, so a request can replace it: a `needs` rule may say which requests fetch it, and `Lora(weights.ref)` (or a string field of another package's request) hands the slot's checkpoint to the call.
A `Lora` given no strength runs at its release's (the `strength` on its Hub card), else 1, as a request's LoRA does.
