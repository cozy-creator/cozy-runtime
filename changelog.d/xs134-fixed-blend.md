`split(..., most=n)` fixes a split's windows from the shape alone, for an op whose result depends on its layout (a blended cut's cross-fade, SeedVR2's per-tile GroupNorms): SeedVR2's tiled VAE decoded differently by free VRAM and by request order (5.9% rel L2 between two layouts of one encode). A refusal inside reclaims and runs the same windows again. Without `most` a split follows memory as before, so released packages keep working.
