Telemetry no longer fails a run. A log message over 200 characters, more than 8 fields, a NaN, a 2^60 seed or a numpy scalar used to raise into the handler or break the seam. They are now clipped (long names keep a digest), dropped or turned into text, and counted. The worker drops an older executor's progress frame it can't journal instead of faulting the attempt. It also reads an executor reply's telemetry members (metrics, caps, adjustments, attribution, and so on) one by one, so a member it can't read takes its default instead of costing the result. A reply too large for one frame now sheds attribution and execution evidence before it gives up its result. Previously that path looped forever once one observation row was left, and its fallback reply never decoded.
