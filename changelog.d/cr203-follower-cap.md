Three fixes from the 2 × 8 GB H3 degree-2 gate failure (run 11275). A process cap the owner writes into a budget cell is applied as soon as a room ask returns, so a group follower (whose cap arrives only there) no longer waits on a stale cap in an op's retry loop; plane budgets still wait for a block boundary. A package that raises its own error from a package call's failure (`raise ... from failure`) fails the attempt without poisoning the executor. The memory refusal judges its verdict against the process cap as well as the GPU, and it reports the GPU as the op found it at its first out-of-memory beside the ledger after the ladder.
