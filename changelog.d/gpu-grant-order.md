Two runs whose single-GPU calls fanned out across one machine no longer deadlock when each then asks for every GPU (runs 1572 and 1573: each waited behind the other's held cards). GPU calls are ordered by their run's admission, then their own: an older run's call takes a younger run's idle cards and waits only on calls actually on them, and a younger run still waits through an older run's gap. A GPU wait now names one run: a real holder or the earliest older waiter, never its own run's ancestor and never a run that is waiting on it.
