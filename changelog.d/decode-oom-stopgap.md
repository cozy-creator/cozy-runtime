Stopgap until memory v3 replaces it: a device out-of-memory in a decode-only component scope, one whose every declared component tiles like a diffusers VAE, no longer fails the run. The Runtime frees the components that scope doesn't hold (e.g. SDXL's UNet and text encoders), releases the allocator cache, and runs the same decode once more with tiling on. The retry is recorded as "decode retried tiled after OOM" in the residency log. Runs 1582/1590/1597 failed this way on 8 GB cards. Any other scope, or a second OOM, fails as before.
