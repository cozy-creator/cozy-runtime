Files carry metadata beside their type. `File.with_metadata({...})` returns a copy of an output file carrying a small JSON map (at most 4 KiB, its keys over any it had), stored with the file in the result; `File.metadata` reads it, and a file a child call returned keeps its child's. `Image`, `Video` and `Audio` gain `metadata`, beside `file` and `description`. The first key the platform reads is `orbit: {degrees, direction, loops}`: a video node shows it turnable. `save_video` and `save_video_stream` take `keyframe_interval` (1: every frame a keyframe, for instant scrubbing).
