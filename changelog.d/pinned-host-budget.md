- The pinned host tier stays under the machine's memory limit. The host budget is now the tightest of `memory.high` and `memory.max` on every cgroup of the process's path and the host's available memory (a cgroup's page cache counts as available); it was `memory.max - memory.current` of the process's own cgroup. Every executor and the tiers the Worker keeps share one machine-wide pinned total (half of what the host has for it) instead of each taking half of what was free at its moment. Idle tenants give pinned memory back, least recently used first, before a new weight set fills and at the end of every turn, and an executor holds its own tier to the host at every stage and pass. What is not pinned is served from the page cache or disk.
