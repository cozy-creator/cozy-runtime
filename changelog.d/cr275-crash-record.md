An executor that crashes (SIGSEGV, SIGBUS, SIGABRT, SIGFPE, SIGILL) on Linux writes every thread's native stack beside faulthandler's Python ones, the crashed thread's frames, what it was answering and `executor crashed: SIGSEGV in <module>+0x<offset> (<symbol>+0x<offset>)` to stderr, which the machine keeps with the run, then dies by the same signal (cr-275). The native wheels carry it as `_kernels._crash`; the call threads get alternate signal stacks.
