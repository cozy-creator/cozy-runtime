A rental whose Runtime is alive but unreachable (hung or stopped, its activity report stale) is idle when no run the Runtime accepted is unfinished, so it releases on its idle clock instead of billing indefinitely. The agent records each run the Runtime accepts in its idle ledger (`unsettled_ms`); two activity reports written after the last acceptance that show no active work settle them. Unreadable activity still holds the rental while an accepted run is unfinished. A ledger from an older agent that saw work holds until the Runtime reports idle.
