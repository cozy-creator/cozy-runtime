`Outputs.join_video` writes a growing MP4 (cl-1210): `ftyp`, one `mdat` per appended video written once, then an index (`moov`) of everything so far. Each revision is an ordinary indexed MP4, published as those parts, and the next keeps all of them but the index, so a machine's reader (Calcifer) fetches only the new video and index instead of the whole join again. `finish` is the last revision byte for byte. `save_video_concat` joins with the same writer; the streaming encoder's packet-copy mode, `finalize_mp4` and the fragment restamping are gone. No author API changes.
