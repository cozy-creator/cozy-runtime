# Installed environment proof

`run.sh` builds and installs the current Runtime wheel, then drives its public
`cozy-environment-proof` executable from `/` with source imports and network access disabled.
Python support prepares exact protocol documents and inspects stored bytes; shell owns every
Runtime process boundary.

The public proof seat is deliberately one-shot and requires a fresh root. The separate private
materializer proof covers content-keyed reuse, wheel-pool sharing and post-publication tamper
refusals.

Runtime observes the protected families and standard-library roots from the actual proof
interpreter. A lying `import_roots` fact refuses against measured ZIP members. The ordinary
resolved fixture exports a genuinely new root and
still imports from the published package environment. A malformed manifest format and the retired
ResolvedWheelSet document are refusal vectors, never compatibility inputs. Two differently named custom wheels
exporting one new root refuse as `package_environment_import_root_duplicate` before uv runs.
