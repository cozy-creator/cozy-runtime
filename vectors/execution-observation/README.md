# ExecutionObservation vectors

These are canonical schema vectors, not claims that a provider run occurred. `request-shape.json`
freezes the closed local observer request. `success.json` and `failure.json` freeze the Runtime
output field set and show that the observer records both terminal classes neutrally. The public
`proofs/acceptance/run.sh` is the evidence: it produces a fresh real observation through the
ordinary provisioned Worker path and exercises the refusal arms.

Tensorhub authenticates the Worker-session projections and alone joins output-abort, provider,
cost, reclaim, candidate, and policy facts into `ModelAdmissionDecision`.
