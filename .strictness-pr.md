Job preparation searched the controller's Python minor directory inside the selected package venv. A 3.14 controller preparing a 3.12 package therefore missed installed child interfaces, even though the selected environment was complete.

Read the venv's `pyvenv.cfg` version (`version_info` from uv or standard `version`) to locate its own site-packages. Metadata discovery starts no package interpreter and executes no startup hooks.

Validation: both layouts pass the focused `tests/test_installed_interface_layout.py` regression with a target minor different from the running controller. No global environment, daemon, rental or GPU was modified.
